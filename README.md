## 东京 VPS 的线路门道：CN2 GIA、CMI、软银差在哪

一句话结论：东京 VPS 的体验差异，八成来自线路而不是配置。同配置的两台东京机器，一台晚高峰流畅，一台丢包严重，差别就在去程和回程走的是什么网。

东京机房的优势是物理距离：到大陆的延迟比美西低一大截，线路好的机器实测能做到 51ms 左右。但这个优势要靠直连线路兑现，普通国际线路晚高峰照样拉胯。有测评作者分享过一个很典型的场景：用普通 BGP 线路的东京 VPS 搭面向日本用户的电商站，国内管理后台晚高峰丢包一度冲到 15%，换成 CN2 优化的机器后延迟直接砍半。

几种常见线路的定位：

- **CN2 GIA**：中国电信的高端承载网，传输路径短、节点少，晚高峰的延迟和丢包控制最好，成本也最高。搬瓦工东京 CN2 GIA 系列定价贵，主要就贵在这条回程上。
- **CMI**：中国移动国际网络。搬瓦工 DC39v2 机房的回程接在 CMI 上，三网方向都能直连回国，对移动用户尤其友好。
- **AS4837**：联通骨干网，联通方向优化的套餐常见，DC39v2 的去程联通走的就是 4837。
- **软银（SoftBank）**：日本本土运营商，往返国内直连、延迟低，LOCVPS 东京和搬瓦工大阪机房用的都是软银。
- **NTT**：日本骨干网，HostDare 东京机房跑在 NTT 网络上。
- **普通 BGP / 国际线路**：便宜，晚高峰质量看运气，适合对国内访问速度不敏感的用途。

选法很直接：这台机器国内访问多，就把预算花在线路上；基本只在日本本地或海外访问，普通线路反而更划算。
